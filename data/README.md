# Data

This project uses the TCGA-PANCAN gene-expression dataset from Hugging Face.

Dataset: Fllamber/TCGA-PANCAN-HiSeq-2770x20530

This dataset contains gene-expression feautures and the target column 'cancer' used for cancer-type classification.

# Data handling

The dataset is loaded from Huggingface in the notebooks.
Raw and intermediate datasets are not stored in the repository
